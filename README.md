
# B8A1 - TypeScript & OOP Assignment

## Assignment Overview

This repository contains my solutions for the B8A1 assignment on Problem Solving with TypeScript and Object-Oriented Programming.

The main goal of this assignment was to practice TypeScript concepts and improve my problem-solving skills by writing code.

## What I Practiced

In this assignment, I worked with:

- Basic Types and Union Types
- Optional and Rest Parameters
- Readonly Tuples
- Interfaces
- Type Narrowing
- Generics and keyof
- Promises and Async Operations
- Classes and Inheritance
- Access Modifiers (public, private, protected)
